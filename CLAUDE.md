# Jared Bangal — portfolio site

Static site: plain HTML, one stylesheet, three scripts (`main.js`,
`particles.js`, `theme.js`). No build step to serve it, no framework, no package
manager. `git push origin main` deploys (Vercel builds from GitHub) to
https://jaredbangal.com.

## Where the rules live — read this first

- **This file** holds only what applies to every task.
- **`.claude/rules/*.md`** hold the area rules and load automatically when a
  matching file is read: `look` (styles.css, images, theme.js), `field`
  (particles.js, build_qr.py), `components` (main.js, index.html, concepts),
  `pages` (every .html, fragments, page builders), `code` (anything in
  `assets/`), `findability` (siteinfo, SEO, OG, vercel.json). If a task touches
  an area without opening its files, read that rule file directly.
- **`docs/design-notes.md`** is the evidence behind the rules, under the same
  `##` headings. It is ~21k tokens: **never read it whole.**
  `grep -n '^## ' docs/design-notes.md`, then Read only the matching section
  with offset/limit — and only before changing the thing that rule describes.

## Token budget

- grep first, then Read with offset/limit. `index.html` (~700 lines),
  `styles.css` (~3,000) and `particles.js` (~900) are never read whole.
- Prefer numbers to pictures: one or two screenshots per check, not a film.
- Reuse `tools/qa/`: `sweep.py` (13 pages × 3 widths × 2 themes — before a
  deploy, not after every edit) and `qr_capture.py` + `qr_decode.py` (the scan
  code). Don't write a new harness for what these already do.
- Edit, don't rewrite, large files; move big blocks with a script.
- Short replies.

## Running it

```bash
python3 serve.py            # http://localhost:8777, sends no-store
python3 serve.py --stamp    # before every deploy
```

- **Every page carries `?v=<md5>` on its asset links, and must.** `vercel.json`
  serves `/assets/*` immutable for a year, so an unstamped page keeps a
  year-old stylesheet. `--stamp` walks every page. A bug that reproduces on
  some pages but not others after a deploy is this.
- Use `serve.py`, not `http.server`. **When a bug won't reproduce**, compare
  `md5 assets/css/styles.css` against the served file first.
- There is no test suite. **Measurement is the test** — re-measure, don't
  recompute. Screenshot 1440 / 860 / 390 before calling visual work done.

## Always true

- **Palette:** cream page, ink text, accent pure black. Never introduce a fifth
  value. The logo orange `#F16813`, the field's blues and `QR_INK` are **never
  tokens** — each would become a second accent.
- **Components reference semantic tokens only** — no raw hex or rgba in a
  component rule.
- **Headings are weight 300 and tight. Don't bold them** (one exception, in
  `pages`).
- **Contrast is measured on rendered pixels** (`rendered-contrast` skill), never
  from computed styles — texture, glass and the canvas are invisible to those.
- **JS is optional by contract**; every motion has a reduced-motion escape;
  touch targets are 44px minimum.
- **Security:** the CSP is `script-src 'self' https://cdnjs.cloudflare.com` with
  no `'unsafe-inline'` — never weaken it. `.env*` is gitignored and must never
  be committed; the repo is public.
- **Honesty:** every stat carries its source; no invented testimonials (FTC,
  16 CFR 465); concepts are labelled concepts; nothing is for sale on
  products.html; the forms post to `action="#"` and say so. Details in `pages`.
- **Pricing** — $600 landing page, $1,200 full site, $120/month care — is
  written in five places; move them together (list in `pages`).
- **Clients are "businesses"**, never "small business" or "startup" — except
  the 27% stat, which keeps its source's wording.
- **After a structural edit to index.html**, print the section ids (`pages`).
- Commit or push only when Jared asks.
